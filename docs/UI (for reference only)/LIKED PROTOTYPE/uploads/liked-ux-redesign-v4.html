02
How to trigger Filter Feed
Was ambiguous — now explicit
1
Sliders icon in top bar
Top bar: Logo · [Sliders icon with badge] · Bell · Avatar. The sliders icon is the universal filter/adjust symbol. Badge shows "2" when 2 filters active.
Why sliders not funnel: The funnel icon means "filter" conceptually. Sliders means "adjust/customise what you see" — closer to what Filter Feed actually does (sort + friends + tags + folders in one surface).
2
Tap → Filter Sheet slides up
Standard bottom sheet: Friends · Tags · Folders · Sort. Multi-select each. Apply button shows active count. Clear all link top-right.
3
Shortcut: tap friend in strip
Tapping a friend avatar in the bottom strip applies a quick friend filter without opening the full sheet. Context pill appears. For multi-filter, open the sheet.
03
Move card from subfolder ABC (N+2) → subfolder XYZ (N+1)
Deep folder move edge case
A
Method 1: Long press → Move
Long press card → context menu → "Move to folder" → opens a folder tree picker sheet: full indented hierarchy, searchable by name. Tap any folder at any depth to move.
This handles all depths. The flat chip row in the drag panel only shows recent/top-level folders. Deep moves use the tree picker.
B
Method 2: Drag + "Browse all"
During drag, the folder panel chip grid shows recent + top-level folders. A "Browse all →" link at the end opens the full tree picker without cancelling the drag.
C
Folder tree picker
Separate modal/sheet. Shows folder hierarchy indented by depth. Search bar at top. Currently selected folder highlighted. Tap to confirm move. Back arrow to cancel.

Notes
1
Symmetric UX with friends
Search bar, collage thumbnail grid, multi-select with checkmark, confirm button — identical interaction pattern to the friends panel.
2
Collage identifies folder visually
No folder name needed at a glance — the thumbnail collage is enough. Name confirms on tap. Color dot = folder color.
3
Search shows sub-folders indented
When "Favorites" matches, its sub-folders appear below it with an indent arrow ↳. They're selectable as individual targets.
4
Not exclusive with sharing
The full drag panel has both tabs: Share (friends/groups) and Move (folders). User can share to Alice AND move to Favorites in one gesture before confirming.
5
"All…" tile opens tree picker
Last tile in folder grid. Tap → full folder hierarchy sheet (indented, searchable). Handles deep N+2 moves without losing drag state.
